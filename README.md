Технологии
Frontend
HTML5: Семантическая структура и верстка страниц.

CSS3: Стилизация, Flexbox для построения сеток, CSS-анимации.

JavaScript (ES6+): Чистый JavaScript без использования фреймворков.

JavaScript: Игровая логика и алгоритмы
Работа с данными: Массивы, объекты, условные операторы и циклы.

Математические функции: Math.random(), Math.floor() для генерации случайных чисел и событий.

Манипуляции со строками: Методы .split(), .reverse(), .join().

Асинхронность: Понимание колбэков, setTimeout, setInterval.

Взаимодействие с пользователем: Использование prompt() и alert().

Инструменты и методологии
Git: Система контроля версий (коммиты, ветки, pull requests).

Модульная структура: Логика каждой игры вынесена в отдельный файл.

Vanilla JS: Отсутствие внешних зависимостей.
